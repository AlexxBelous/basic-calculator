# 🧮 Simple Calculator

Учебный пет-проект: простой калькулятор для выполнения базовых арифметических операций.

## 🛠️ Стек технологий

- **HTML5** — семантическая разметка

- **Sass/SCSS** — стилизация приложения

- **Vanilla JS (ES6+)** — логика калькулятора и работа с DOM

- **Vite** — сборщик проекта и dev-сервер

---

## 📌 Функционал приложения

- [ ] Выполнение базовых арифметических операций

- [ ] Сложение, вычитание, умножение и деление

- [ ] Ввод чисел с помощью кнопок интерфейса

- [ ] Отображение текущего выражения и результата

- [ ] Очистка введённых данных
